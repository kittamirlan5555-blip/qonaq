# Сверка с учётом: «занято по видео» против оплаченного (B3)

```bash
python -m qonaq reconcile --events runs/live_billiard/events.sqlite --sessions paid.csv \
    --site configs/sites/billiard_example.yaml [--map tables.yaml] [--date 2026-11-14] [--send]
```

Результат — рядом с журналом (или в `--out`): `reconcile.html` (отчёт владельцу), `reconcile.json`,
`reconcile_telegram.txt` (строки для Telegram; `--send` отправляет их в чат владельца заведения
`TELEGRAM_VENUE_CHAT_ID`). Пример на синтетике: `docs/examples/reconcile_example.html`.

## Что считается

| Профиль | Строка отчёта | Как считается |
|---|---|---|
| billiard | **Игра без счётчика** | сессия игры по видео не пересекается ни с одной оплаченной сессией этого стола (с допусками) |
| billiard | **Играли дольше оплаченного** | часть сессии по видео до начала / после конца оплаченной (с допусками) |
| billiard | **Счётчик шёл, стол пустой** (в пользу гостя) | часть оплаченной сессии, где по видео игры нет (к концу игры добавляется 5 мин на расчёт) |
| restaurant | **Стол занят, чека нет** | сессия стола (посадка → уход) не пересекается ни с одним чеком этого стола |

Деньги: минуты × тариф стола (`billiard.tariffs` / `tariff_per_hour` в конфиге объекта или `tariff` в карте
столов). Для ресторана — «≈ средний чек» (`business.avg_check_kzt`), это оценка, не факт.

**Допуски** (флаги или ключи в `--map`): `tolerance_s` (120 с) — часы кассы и видео расходятся;
`rounding_min` (5 мин) — учёт округляет сессию вверх; `min_minutes` (10 мин) — короче не показываем.

**Когда система не видела** (перезапуск, отключение света, камера не отвечала) — ничего не утверждаем: live раз
в минуту пишет в журнал отметку `heartbeat` с камерами, от которых шли кадры. Оплаченные сессии вне периода
записи — в счётчике «вне периода записи», в расхождения не попадают.

## Формат CSV (гибкий)

- Разделитель `;`, `,` или табуляция; кодировка UTF-8 (в т.ч. с BOM) или Windows-1251 (выгрузка Excel).
- Первая строка — заголовок. Колонки узнаются по названию (регистр не важен):
  - стол: `Стол`, `table`, `№ стола`, `Номер стола`, `Ресурс`, `Место`;
  - начало: `Начало`, `start`, `Открыт`, `Время начала`, `Открытие`;
  - конец: `Конец`, `end`, `Закрыт`, `Время окончания` — **или** длительность: `Длительность`, `duration`,
    `Минут`, `Время игры` (число — минуты, или `Ч:ММ`);
  - сумма (необязательно): `Сумма`, `amount`, `Итого`, `Стоимость`, `Оплачено`;
  - дата (необязательно): `Дата`, `date`.
- Время: `2026-11-14 21:10`, `14.11.2026 21:10`, `14.11.26 21:10`, ISO с `T`, или только `21:10` — тогда нужен
  `--date` (рабочий день). Смена после полуночи: время раньше `--day-start` (6:00) относится к следующему
  календарному дню; конец раньше начала (`23:30–01:10`) — тоже следующий день.
- Сумма: `3 750,00`, `3750`, `3,750.00` — пробелы и символ валюты игнорируются.

Пример (`docs/examples/billiard_paid_example.csv`):

```
Стол;Начало;Конец;Сумма
Стол 1;20:02;20:10;333
Стол 2;20:20;21:10;2083
```

## Карта столов (`--map tables.yaml`)

Без карты «Стол 4» сопоставляется с зоной `B4` (бильярд) или `T04`/`T4` (ресторан) по последнему числу
в названии. Если названия в учёте другие:

```yaml
timezone: Asia/Almaty
tolerance_s: 180        # часы кассы плавают сильнее
rounding_min: 10        # учёт считает по 10 минут
min_minutes: 10
tables:
  "Пул 1":       {zone: B1, camera: hall_1, tariff: 2500}
  "Русский 1":   {zone: B5, camera: hall_2, tariff: 4000, name: "Русский бильярд 1"}
  "VIP":         {zone: B6, camera: vip, tariff: 6000}
```

Столы из учёта без зоны на камерах перечисляются в отчёте отдельной строкой.

## Журнал прогона файла

У прогона записи (`run-file`, `billiard synth --run`) время в журнале — секунды от начала видео. Нужен
`--video-start "2026-11-14 20:00"` — местное время начала записи (видно в OSD регистратора).

## Как говорить об этом с владельцем

Отчёт показывает **расхождение двух источников**, а не «кто украл». Часы кассы уходят, сессию переносят на другой
стол, компания доплачивает наличными одной строкой. Каждый отрезок проверяется по записи регистратора за
указанное время. В текстах — только стол и время: «Стол 4, 21:10–22:40, по учёту не оплачено».
