## Как запустить (кратко)

```bash
python -m venv .venv
# Windows: .venv\Scripts\activate      Linux/macOS: source .venv/bin/activate
pip install -e ".[dev]"
python scripts/fetch_videos.py
python -m qonaq doctor
```

## Блокеры и обходные пути

- **PyTorch в облаке не поставился.** `download.pytorch.org` закрыт сетевой политикой сессии, а сборка
  с PyPI тянет ~3 ГБ CUDA-библиотек со скоростью < 1 МБ/с. Обход: детектор YOLOX через `onnxruntime`
  (см. DECISIONS D-003). Адаптер Ultralytics написан, но **в этой сессии не запускался** (если ниже
  не сказано обратное).
